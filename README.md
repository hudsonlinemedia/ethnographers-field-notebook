# Prof Honey's Field Notebook

Beta test copy of *The Ethnographer's Field Notebook*, an ethnography field game guided by Prof Honey. Students use the SCORM version in Brightspace.

## Prof Honey's glasses

In `index.html`, find `const GLASSES = 'clear';` and change it to `'sun'` for the red cat-eye sunglasses, or back to `'clear'` for clear lenses with blue eyes.
